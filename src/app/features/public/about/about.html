About

Money tools should tell the truth

Financial Planner is an independent project, built in India, to answer one question well: how much can I actually spend?

Why it exists

Balances across several banks, a credit card with an unpaid statement, a UPI wallet, a loan EMI and a few subscriptions — none of the apps we tried could say what was genuinely free to spend. So we built one that treats cards, EMIs and upcoming bills as first-class, and keeps the maths explainable.

It is built in the open with its users: the feedback hub drives the roadmap, and every release is written up in the blog.

Clarity first

Every figure should be explainable. If we can’t show how a number was reached, it doesn’t ship.

Privacy by default

Your data is scoped to your account and used to run the app — not sold, not advertised against.

Built with you

Vote on ideas, report problems and follow progress on the public roadmap.

Under the hood

An Angular progressive web app talking to an ASP.NET Core API on PostgreSQL. Money-critical operations are transactional and serialised, schema changes are versioned SQL migrations, and sessions are bound to devices.
